# nxnative guide

An unofficial, plain-English guide to **[nxnative](https://github.com/seedds/nxnative)**, the open-source tool that turns a Nintendo Switch game you own into a native iPhone, iPad or Apple silicon Mac app. It is not an emulator: the game's own code runs on the Apple chip, and the Switch graphics are rebuilt on Metal.

The full guide lives at **[nxnative.org](https://nxnative.org)**. This repository only collects the links and a short summary.

> Not affiliated with seedds, Nintendo or Apple. No files, games, keys or apps are hosted here or on the site, and neither explains how to obtain them. Use only games you own.

## Quick facts (October 2026)

- **Games:** 93 games tested on Mac or iPhone, 18 of them at 60 fps with a specific update. See the [nxnative compatibility list](https://nxnative.org/games/).
- **Play on:** iPhone 15 Pro or newer (iOS 26+), M1 iPad or newer (iPadOS 26+), or an Apple silicon Mac.
- **Build on:** a Mac on macOS 26.6+ with Xcode 27.1. Full list on the [requirements page](https://nxnative.org/requirements/).
- **Install:** sideload the IPA with AltStore, Sideloadly or LiveContainer. Steps in [how to use nxnative](https://nxnative.org/install/).
- **Controls:** touch layouts are built in; a controller hides them. See [controllers for nxnative](https://nxnative.org/controllers/).
